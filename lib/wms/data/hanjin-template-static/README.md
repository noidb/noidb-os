# 한진택배 업로드 서식(고정형) — 운영용 고정 템플릿

이 폴더의 `한진택배_쿠팡_고정형_기준서식.xlsx`는 **Git에 커밋되는** 검증된 원본 서식이다
(2026-08-24 3차 수정으로 신설 — `lib/wms/data/hanjin-template/`와 달리 gitignore 대상이
아니다). 로컬 개발 환경과 Vercel 운영 환경이 항상 완전히 동일한 파일을 쓰도록 하기 위함이다.

## 왜 이 폴더가 필요했나

이전에는 원본 서식을 Google Drive(`GOOGLE_DRIVE_HANJIN_SHIPMENT_FOLDER_ID` 폴더)나 로컬
개발 전용 gitignored 폴더(`lib/wms/data/hanjin-template/`)에서 찾았다. 그런데 실제 그 Drive
폴더에는 "한진택배"로 시작하지만 완전히 다른 서식("씨엘링크" 등)이 들어있었고, 우리가 검증해온
실제 "쿠팡(고정형)" 서식은 "샘플파일_한진택배..."로 시작해 이름 조건에 안 맞았다. 그 결과
운영(Vercel)에서는 엉뚱한 파일을 잘못 읽거나 아무것도 못 찾아 업로드파일 생성이 실패했다.

## 이 파일이 하는 역할

- `lib/wms/hanjin-upload.ts`가 이 파일에서 **헤더(1행)와 열 구조**만 결과 파일에 그대로
  가져다 쓴다. 이 파일 안에 남아있는 물류센터별 과거 데이터 행(대구2/대구3/안산3/인천30/
  인천36/인천4)은 우편번호 등 발주서 원본에 없는 값을 보충할 때만 조회용으로 쓰이고, 결과
  파일에는 절대 복사되지 않는다(과거 행 없이 매번 새로 작성).
- 이 파일 자체는 시스템이 **읽기만** 하고 절대 수정하지 않는다.

## 갱신하려면

한진택배가 새 서식을 내려주면, 이 파일을 교체하는 커밋을 올리고(코드 리뷰 대상) 실제 API로
재검증한 뒤 배포한다. G드라이브나 파일명 관례에 의존하지 않는다.
