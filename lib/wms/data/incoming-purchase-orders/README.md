`/wms/work-center`에서 자동으로 읽어 표시합니다.

- 파일명은 상관없습니다. 이 폴더 안의 `.xlsx` 파일을 전부 읽습니다.

  전화번호 등 민감한 정보가 들어있기 때문입니다.
- 이 폴더의 파일은 시스템이 **읽기만** 하고, 절대 수정하지 않습니다.
- 오래된 발주서 파일을 지워도 되고, 그대로 두어도 됩니다 (그대로 두면 계속 화면에 표시됩니다).
