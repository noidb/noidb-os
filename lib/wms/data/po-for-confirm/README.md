# 발주확정용 원본 파일 폴더

쿠팡 서플라이허브에서 다운로드한 "PO_FOR_CONFIRM(발주번호).xlsx" 파일을 이 폴더에 넣으면
피킹 완료 화면에서 발주확정 서류를 생성할 때 이 파일을 원본 템플릿으로 사용합니다.

- 파일명에 발주번호 숫자만 포함되어 있으면 인식합니다 (예: `PO_FOR_CONFIRM(139142928).xlsx`).
- 이 폴더의 파일은 시스템이 **읽기만** 하고, 절대 수정하지 않습니다. 발주확정 서류는 이 파일을
  읽어와 확정수량(I열)만 바꾼 **새 파일**로 생성됩니다.
- 이 폴더의 엑셀 파일은 **절대 Git에 커밋되지 않습니다** (`.gitignore`에서 제외됨).
