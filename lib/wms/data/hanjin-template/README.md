# 한진택배 업로드 서식(고정형) 폴더

한진택배가 제공하는 "한진택배 서식_쿠팡(고정형)_YYYYMMDD.xlsx" 파일을 이 폴더에 넣으면,
피킹 완료 화면에서 운송장 출력용 업로드파일을 생성할 때 이 파일을 기준으로 사용합니다.

- 파일명이 "한진택배"로 시작하고 `.xlsx`로 끝나면 인식합니다. 여러 개 있으면 수정 시각이
  가장 최근인 파일을 씁니다.
- 이 폴더의 파일은 시스템이 **읽기만** 하고, 절대 수정하지 않습니다. 업로드파일은 이 파일을
  읽어와 필요한 행을 **추가**만 한 새 파일로 생성됩니다 (기존 행/서식은 그대로 유지).
- 이 파일은 물류센터별 수취인 주소(전화/우편번호/주소)를 담은 기준표 역할도 합니다 — 새 물류센터로
  처음 출고하는 경우 이 파일에 해당 물류센터 행이 없으면 자동으로 채울 수 없다는 경고가 뜹니다.
- 이 폴더의 엑셀 파일은 **절대 Git에 커밋되지 않습니다** (`.gitignore`에서 제외됨).
