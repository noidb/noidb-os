# NOID-B 서플라이허브 연결

쿠팡 Supplier Hub의 입고상세내역, WIMS와 상품공급상태 관리 화면에서 검색 결과의 모든 페이지를 NOID-B로 전달하는 Chrome/Edge 확장 기능입니다. 로그인 정보와 비밀번호는 읽거나 저장하지 않습니다.

## 최초 한 번 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다. Edge는 `edge://extensions`입니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 `browser-extension/noidb-supplier-sync` 폴더를 선택합니다.

## 기존 설치 업데이트 (1.3.0)

이 폴더를 이미 설치했다면 Chrome/Edge의 확장 프로그램 관리 화면에서 `NOID-B 서플라이허브 연결`의 새로고침 버튼을 한 번 누른 뒤 NOID-B 사이트 탭도 새로고침합니다. ZIP으로 설치했다면 최신 ZIP을 기존 설치 폴더에 풀고 확장 프로그램을 새로고침합니다. 이번 업데이트의 권한은 기존과 같은 `storage`뿐이며, 쿠키·비밀번호·전체 탭 읽기 권한을 추가하지 않습니다.

## 주간 입고 업무

1. 같은 Chrome/Edge에서 NOID-B의 `주간 업무` 화면(`/wms/inbound`)을 열고 기간을 선택합니다. 이번 밀린 업무는 최근 한 달, 평소에는 최근 일주일을 사용합니다.
2. `이 기간 업무 준비`를 누르면 서플라이 허브의 입고상세내역 탭이 열립니다. 이미 분석한 기간은 `최신 자료로 다시 확인`으로 표시됩니다. 로그인이 필요하면 그 탭에서 로그인과 본인 인증만 완료합니다.
3. 선택 기간의 실제 입고/반출일자로 검색하고 전체 페이지를 차례로 확인합니다. 다운로드 파일을 옮기거나 날짜별로 선택할 필요가 없습니다.
4. 검색 건수·각 페이지 행수·날짜 범위·열 구성·반복 페이지를 확인하고, 마지막에 첫 페이지를 새로 조회해 검색 건수와 첫 페이지가 바뀌지 않았는지 재검증합니다. 검증한 전체 결과만 요청한 NOID-B 탭으로 전달하고 NOID-B 탭으로 돌아갑니다.
5. NOID-B가 받은 결과의 분석을 완료했다고 확인한 뒤에만 해당 전송 자료를 지웁니다. 다른 탭이나 이전 요청의 확인으로 자료를 지우지 않습니다.

이 수집 기능은 서플라이 허브의 조회 화면만 사용합니다. 거래처 발송, 쿠팡 쿠폰 등록·단종 신청, 운영 수량 변경은 실행하지 않습니다. 반출 행도 원본 그대로 전달하고 쿠폰 대상 제외는 NOID-B의 입고 분석에서 처리합니다. 동일 SKU가 여러 번 입고된 행도 원본대로 보존합니다.

조회 도중 건수가 달라지거나 일부 페이지를 읽지 못하면 결과를 전송하지 않고 주간 업무 화면에 이유를 표시합니다. 페이지별로 전체 화면이 새로 열려도 수집 진행을 이어가며, 최대 10,000행·93일·30분 이내의 조회를 지원합니다. Chrome/Edge의 로그인 화면이 다른 도메인에서 열리면 해당 탭에서 인증을 마치면 됩니다. 지원 도메인의 서플라이 허브 화면으로 돌아온 뒤 이어서 조회합니다.

확장이 설치되지 않았거나 연결되지 않으면 주간 업무 화면에서 Drive/업로드 자료로 이어갈 수 있습니다. 브라우저 수집과 다운로드 자료 사용 여부는 화면에서 구분합니다. 지원 사이트는 운영 주소 `https://noidb-os.vercel.app`와 개발용 `http://localhost:3000`의 입고 화면입니다.

### 검증

`node scripts/verify-weekly-extension.cjs`는 39행/4페이지, 205행/21페이지, 빈 결과, 기간 밖 행, 필터 잔존, 반복·누락 페이지, 수집 중 건수 변경, 최종 새 조회의 변경 감지, 타 탭/타 출처 메시지, 잘못된 ACK와 부분 전송 차단을 검증합니다. 쿠팡은 후속 페이지에 검색 건수 표를 생략할 수 있어 최초 확인한 건수로 페이지 행수를 검증하고 마지막 새 조회에서 건수를 다시 확인합니다. 실제 서플라이 허브의 조회 폼·표·페이지 구조는 2026-09-07에 읽기 전용으로 확인했습니다. 설치된 확장을 통한 운영 자료 자동 전송 검증은 별도로 수행해야 합니다.

## WIMS 사용

1. Supplier Hub의 `상품 등록 상태 확인` WIMS 화면을 엽니다.
2. 확인할 등록일 등 검색 조건을 맞추고 검색합니다.
3. 오른쪽 아래 `WIMS 전체를 NOID-B로 전송`을 한 번 누릅니다.
4. NOID-B AI 상품등록 탭은 즉시 열리고, Supplier Hub 탭에서는 페이지당 100개로 바꾼 뒤 모든 숫자 페이지를 차례로 수집합니다.
5. `총 검색 건수 = 페이지별 예상 행수 합계 = 실제 수집 건수`이고 모든 행의 컬럼 수가 같으며 반복 페이지가 없을 때만 전송됩니다.
6. NOID-B AI 상품등록의 `등록 진행상황`에서 자동 분류와 읽기 전용 제품DB 대조 결과를 확인합니다.
7. 실제 연결 후보가 정확할 때만 `검수완료 안전 연결`을 누릅니다.

수집 중 페이지가 반복되거나 페이지 경계에 같은 행이 다시 나타나거나 일부 행·컬럼이 누락되면 확장 기능은 결과를 저장하거나 전송하지 않습니다. 원래 Supplier Hub 탭에서 오류 안내를 확인한 뒤 다시 시도하세요.

검색 결과가 1,000건을 넘으면 등록일 범위를 줄여 1,000건 이하로 검색한 뒤 전송하세요. 제품DB 변경 API와 동일한 안전 한도로 맞춰 부분 처리되지 않게 차단합니다.

## 상품공급상태 관리 사용

1. Supplier Hub의 `상품공급상태 관리` 화면을 열고 조회합니다. 계정이나 메뉴 이동에 따라 주소가 달라도 필수 열이 있는 실제 표를 찾아 버튼이 나타납니다.
2. 오른쪽 아래 `상품공급상태 전체를 NOID-B로 전송`을 한 번 누릅니다.
3. 확장 기능이 페이지당 표시 개수를 최대로 바꾸고 모든 페이지를 차례로 수집합니다.
4. 전체 건수·각 페이지 행수·필수 열·반복 페이지·반복 SKU를 모두 검증한 뒤에만 AI 상품등록의 `등록 진행상황·상품 운영정보`로 전달합니다.
5. NOID-B의 진단 결과를 확인하고 `안전 항목 반영`을 누르면 기존 제품DB 행만 갱신합니다. 새 행은 만들지 않고, 기존 SKU의 바코드도 바꾸지 않습니다.

부분 수집이나 표 구조 변경이 감지되면 아무것도 전달하지 않습니다. 최대 10,000건까지 한 번에 수집할 수 있습니다.
