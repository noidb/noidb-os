# NOID-B 서플라이허브 연결

쿠팡 Supplier Hub의 WIMS 화면에서 현재 검색 결과의 모든 페이지를 NOID-B AI 상품등록으로 전달하는 Chrome/Edge 확장 기능입니다. 로그인 정보와 비밀번호는 읽거나 저장하지 않습니다.

## 최초 한 번 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다. Edge는 `edge://extensions`입니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 `browser-extension/noidb-supplier-sync` 폴더를 선택합니다.

## 사용

1. Supplier Hub의 `상품 등록 상태 확인` WIMS 화면을 엽니다.
2. 확인할 등록일 등 검색 조건을 맞추고 검색합니다.
3. 오른쪽 아래 `WIMS 전체를 NOID-B로 전송`을 한 번 누릅니다.
4. NOID-B AI 상품등록 탭은 즉시 열리고, Supplier Hub 탭에서는 페이지당 100개로 바꾼 뒤 모든 숫자 페이지를 차례로 수집합니다.
5. `총 검색 건수 = 페이지별 예상 행수 합계 = 실제 수집 건수`이고 모든 행의 컬럼 수가 같으며 반복 페이지가 없을 때만 전송됩니다.
6. NOID-B AI 상품등록의 `등록 진행상황`에서 자동 분류와 읽기 전용 제품DB 대조 결과를 확인합니다.
7. 실제 연결 후보가 정확할 때만 `검수완료 안전 연결`을 누릅니다.

수집 중 페이지가 반복되거나 페이지 경계에 같은 행이 다시 나타나거나 일부 행·컬럼이 누락되면 확장 기능은 결과를 저장하거나 전송하지 않습니다. 원래 Supplier Hub 탭에서 오류 안내를 확인한 뒤 다시 시도하세요.

검색 결과가 1,000건을 넘으면 등록일 범위를 줄여 1,000건 이하로 검색한 뒤 전송하세요. 제품DB 변경 API와 동일한 안전 한도로 맞춰 부분 처리되지 않게 차단합니다.
