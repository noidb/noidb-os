# NOID-B 서플라이허브 연결

쿠팡 Supplier Hub의 WIMS 화면에서 현재 표시된 상품 행을 NOID-B 작업센터로 전달하는 Chrome/Edge 확장 기능입니다. 로그인 정보와 비밀번호는 읽거나 저장하지 않습니다.

## 최초 한 번 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다. Edge는 `edge://extensions`입니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 `browser-extension/noidb-supplier-sync` 폴더를 선택합니다.

## 사용

1. Supplier Hub의 `상품 등록 상태 확인` WIMS 화면을 엽니다.
2. 검색 조건과 한 페이지 표시 개수를 원하는 범위로 맞춥니다.
3. 오른쪽 아래 `NOID-B로 WIMS 전송`을 누릅니다.
4. NOID-B AI 상품등록의 `등록 진행상황`이 열리면 자동 분류와 읽기 전용 제품DB 대조 결과를 확인합니다.
5. 실제 연결 후보가 정확할 때만 `검수완료 안전 연결`을 누릅니다.

현재 버전은 화면에 표시된 페이지의 행만 전송합니다. 여러 페이지가 있으면 페이지별로 전송해야 합니다.
