# NOID-B 주간 업무 사용 설명서

입고 확인 · 30% 쿠폰·광고등록 · 거래처 발주 · 재발주요청 · 단종 신청

2026년 9월 8일 개정판 v1.4 | 브라우저 연결 확장 1.3.0

## 매주 한 번, 이 순서대로 하세요

**기간·자료 준비 → 쿠폰 상품 선택·미입고 검토 → 파일 받기·완료**

1. [주간 업무 화면 열기](https://noidb-os.vercel.app/wms/inbound). 처음 밀린 업무는 **최근 한 달**, 평소에는 **최근 일주일**을 선택합니다.
2. **이 기간 업무 준비**를 누릅니다. 이미 분석한 기간은 **최신 자료로 다시 확인**으로 표시됩니다.
3. 분석 기간과 **자료의 최신 실제 입고일**을 확인합니다. 날짜 기준은 **실제 입고일**입니다. **자료 확인 필요** 상품은 미납 목록에서 제외되므로 원문을 보완한 뒤 다시 분석하세요.
4. **쿠폰 적용 상품을 선택하세요**에서 곧 단종되거나 생산 계획이 없는 SKU의 체크를 해제합니다. 선택 기간의 입고수량 합계가 **정확히 1개인 SKU** 중 체크한 상품만 쿠폰에 들어갑니다.
5. **미입고 상품을 검토하세요**에서 처리 방법을 고릅니다. 새로 구입할 상품은 **거래처 발주**, 보유 재고로 다시 보낼 상품은 **재발주요청 · 재고 있음**, 생산 종료는 **단종 · 생산 종료**, 나중에 판단할 상품은 **이번에는 보류**입니다.
6. **전체 파일 한 번에 받기 ↓**를 누릅니다. 쿠폰·광고만 받으려면 **쿠폰·광고 파일 받기 ↓**, 쿠폰 엑셀만 먼저 받으려면 **쿠폰만 받기**를 누릅니다.
7. 실제 등록·발송·신청을 마친 항목만 완료로 표시하고, 마지막에 **이번 주간 업무 완료**를 누릅니다.

### 한 번에 준비되는 파일

| 할 일 | 받는 파일 |
| --- | --- |
| 선택 상품에 30% 쿠폰·광고 등록 | 체크한 SKU의 쿠폰 엑셀 + 같은 상품의 옵션ID만 최대 500개씩 담은 광고 엑셀 |
| 거래처에 상품 발주 | 거래처별 사진 발주서 PNG + 발주 엑셀 |
| 보유 재고로 쿠팡에 재발주 요청 | 원래 발주번호·SKU별 정확한 미납수량을 담은 엑셀 |
| 생산 종료 상품 단종 신청 | 선택한 SKU의 공문 PDF + SKU 엑셀 |

### 파일로 바로 테스트하려면

**이미 받은 파일 사용 · 브라우저 연결 안내**를 펼친 뒤 **입고상세내역 파일 선택**을 누르고, 서플라이 허브에서 받은 XLSX를 선택하세요. 확장 설치 없이 분석할 수 있습니다.

**테스트 중에는 파일 생성까지만 해도 됩니다.** 완료 버튼은 실제 등록·발송·재발주 요청·단종 신청을 마친 뒤에만 누르세요.

## 01. 기간과 입고 자료 준비

### 기간 선택

**최근 한 달**은 밀린 업무를 처음 정리할 때, **최근 일주일**은 매주 처리할 때 사용합니다. 날짜 칸에서 시작일과 종료일을 직접 바꿀 수도 있습니다. 기간을 바꾼 뒤에는 **이 기간 업무 준비**를 다시 눌러야 결과가 바뀝니다.

### 자료를 가져오는 세 가지 방법

| 방법 | 사용 순서 |
| --- | --- |
| 브라우저 자동 가져오기 | 연결 확장을 준비한 Chrome/Edge에서 **이 기간 업무 준비**를 누릅니다. 열린 서플라이 허브 탭에서 필요하면 로그인·본인 인증을 마치고 전체 조회가 끝날 때까지 기다립니다. |
| Drive의 파일 사용 | **이미 받은 파일 사용 · 브라우저 연결 안내**를 펼쳐 **Drive에 저장된 파일로 준비**를 누릅니다. 연결이 없을 때도 Drive 파일을 확인합니다. 자동 수집 중 오류가 났다면 이 방법이나 업로드로 전환하세요. |
| 받은 파일 직접 선택 | 같은 안내에서 **입고상세내역 파일 선택**을 누릅니다. XLSX 여러 개를 함께 선택할 수 있습니다. 파일당 10MB 이하, 총 30MB 이하, 최대 30개입니다. |

Drive 입고 파일 보관 위치는 `쿠팡데이터 / 입고상세내역 다운로드`입니다. **발주서 ZIP이 아니라 입고상세내역 XLSX**를 사용하세요. Drive 조회가 안 되면 안내 안의 **Google Drive 다시 연결 ↗**을 이용하거나 XLSX를 직접 선택하세요.

### 자동 가져오기: 확장 준비는 처음 한 번

1. 화면의 **브라우저 연결 확장 다운로드 ↓**로 ZIP을 받아 압축을 풉니다. [확장 ZIP 바로 받기](https://noidb-os.vercel.app/downloads/noidb-supplier-sync.zip)
2. Chrome 주소창에 `chrome://extensions`를 입력하고 개발자 모드를 켭니다. Edge는 `edge://extensions`입니다.
3. 처음 설치한다면 **압축해제된 확장 프로그램을 로드합니다**를 눌러 `manifest.json`이 있는 폴더를 선택합니다.
4. 이미 설치했다면 새 ZIP의 파일을 기존 설치 폴더에 덮어쓴 뒤 **NOID-B 서플라이허브 연결**의 새로고침을 누릅니다. 버전 **1.3.0**을 확인하고 NOID-B 사이트도 새로고침합니다.

### 분석 후 꼭 볼 곳

**분석 기간**, **자료의 최신 실제 입고일**, **자료 확인 안내**를 확인하세요. 자료 목록에 오래된 파일명이 있어도 쿠폰은 선택 기간의 실제 입고수량으로 계산합니다. 최신 입고가 빠졌다면 자료를 갱신한 뒤 다시 준비하세요.

## 02. 쿠폰 선택과 미입고 기준

### 쿠폰은 “선택 기간 입고 합계 1개”만

입고상세내역의 **실제 입고일**이 선택 기간 안인 기록을 SKU별로 합칩니다. 여러 날짜나 발주서에 같은 SKU가 있어도 모두 합쳐 **정확히 1개**일 때만 쿠폰 후보가 됩니다.

| 실제 입고 기록 예시 | 쿠폰 후보 여부 |
| --- | --- |
| 선택 기간에 1개 입고 | 후보에 포함 |
| 월요일 1개 + 금요일 1개 입고 | 합계 2개이므로 제외 |
| 2개 입고 후 1개 반출 | 입고 합계는 2개이므로 제외. 반출로 1개를 만들지 않습니다. |

### 쿠폰을 적용할 상품만 체크하세요

1. **쿠폰 적용 상품을 선택하세요**에서 SKU 또는 상품명을 검색합니다. 개별 체크를 해제해 곧 단종되거나 생산 계획이 없는 상품을 제외하세요.
2. **전체 선택 / 전체 해제**는 검색 결과만이 아니라 이 작업의 전체 쿠폰 후보에 적용됩니다. **쿠폰 적용 N개 · 제외 N개**를 확인하세요.
3. **쿠폰 선택 저장됨**을 확인하고 **쿠폰·광고 파일 받기 ↓**를 누릅니다. 체크한 SKU만 30% 쿠폰과 광고등록 파일에 들어갑니다. 선택을 바꾸면 파일도 새로 받으세요. 쿠폰 엑셀만 필요하면 **쿠폰만 받기**를 누릅니다.

체크 해제는 **이번 작업의 쿠폰에서만 제외**합니다. 입고 자료를 삭제하거나 상품을 영구 단종으로 바꾸지 않습니다. 다음 작업에서 다시 검토할 수 있습니다. 실제 쿠팡 등록 후 **쿠팡에 등록했어요**를 누르면 **쿠팡 등록 완료 · 선택 고정**으로 바뀌며 선택을 수정할 수 없습니다.

### 미입고는 “실제 입고된 발주서의 부족분”만

선택 기간에 **실제 입고수량이 1개 이상 확인된 발주서**를 골라 원문·발주이력·입고내역을 대조합니다. 세 자료의 수량과 연결이 확인되고, 해당 발주서에서 **실제 누적 입고가 확정수량보다 적거나 0인 SKU**만 미입고입니다. 전량 입고된 SKU와 근거가 불확실한 상품은 제외합니다.

**미입고 = 발주 확정수량 - 실제 누적 순입고수량(입고 - 반출)**

예를 들어 한 발주서의 A는 확정 10개·입고 10개, B는 확정 10개·입고 6개, C는 확정 5개·입고 0개라면 **B 4개와 C 5개**가 미입고입니다. 이 발주서는 A·B의 실제 입고가 확인되었기 때문입니다.

**아직 어느 SKU도 입고되지 않은 발주서는 제외**합니다. 오늘 확정했거나 발송했더라도 입고가 전혀 잡히지 않으면 포함하지 않습니다. 입고예정일로 후보를 추가하지 않습니다. 지난 보류·미발송 건도 실제 입고 근거가 있는 발주서만 다시 대조합니다.

## 03. 미납 원문 대조와 자료 확인

**미납 목록에는 정확한 부족수량이 확인된 상품만 표시됩니다.** 실제 입고가 시작된 발주서라도 원문이 없거나 수량이 맞지 않으면 미납으로 확정하지 않습니다.

### 같은 발주번호·SKU로 세 자료를 맞춥니다

| 확인할 자료 | 대조하는 내용 |
| --- | --- |
| 발주서 원문 H열 **업체납품가능수량** | `_발주이력`의 확정수량과 같은지 확인합니다. 원문의 빈칸과 확정 0개는 구분합니다. |
| 발주서 원문 I열 **입고수량** | 입고상세내역에서 집계한 같은 발주번호·SKU의 실제 누적 입고수량과 맞는지 검산합니다. |
| 확인된 부족수량 | 위 대조와 상품 연결을 모두 통과한 뒤 **확정수량 - 실제 누적 순입고수량**이 양수인 건만 미납으로 남깁니다. |

### “자료 확인 필요”는 미납 건수가 아닙니다

**자료 확인 필요 · N개 SKU · 미납 목록에서 제외**를 펼쳐 발주번호·SKU와 사유를 확인하세요. 원문 누락, 확정수량 불일치, 입고수량 불일치, 발주번호·SKU 연결 불명확 등이 표시됩니다.

이 상품들은 **미납 목록, 거래처 발주 파일, 재발주요청 파일에서 제외**됩니다. 수량을 직접 입력하거나 주문수량 확인을 체크해도 원문 검증을 대신할 수 없습니다. 원문과 이력을 바로잡은 뒤 **최신 자료로 다시 확인**을 눌러야 합니다.

### 최근 한 달 입고에도 더 오래된 발주서가 필요할 수 있습니다

기간 선택은 **실제 입고일 기준**입니다. 예를 들어 8월에 발주하고 9월에 입고된 상품은 9월 입고를 확인하더라도 8월 발주서 원문이 필요합니다. 자료 확인 안내에 나온 발주번호의 원문을 보완하세요.

입고상세내역 XLSX만 올렸다고 발주서 원문 대조까지 완료되는 것은 아닙니다. **업로드 발주서 원문 확인**에서 실제 확인한 발주서 파일을 볼 수 있습니다.

### 원문을 보완하고 다시 분석하면

같은 기간의 바로 이전 작업에서 미완료인 **처리 방법·사용자 주문수량·사진·거래처**를 같은 SKU에 이어받습니다. 다만 원문이 바뀌었으므로 **주문수량 확인 체크는 해제**됩니다. 현재 재고와 배송 상태를 다시 확인한 뒤 체크하세요.

새 미납 목록에서 빠진 SKU는 이어받지 않습니다. 이미 발송·요청·신청한 완료 기록은 이전 작업에 남으며 새 작업의 완료 상태로 복사되지 않습니다.

## 04. 쿠폰과 광고등록 파일 함께 받기

**최종 쿠폰 선택 상품을 그대로 광고등록 대상으로 사용합니다.** 쿠폰은 SKU ID, 광고등록은 해당 SKU에 연결된 **옵션ID**를 사용합니다. 상품 링크의 `vendorItemId=86399202564`에서 광고 옵션ID는 `86399202564`입니다.

### 선택부터 파일 받기까지

1. **쿠폰 적용 상품을 선택하세요**에서 단종 예정 등 제외할 SKU의 체크를 해제하고 **쿠폰 선택 저장됨**을 확인합니다.
2. **선택한 쿠폰 SKU의 광고등록 파일**에서 옵션ID 확인 결과를 봅니다. 같은 옵션ID는 한 번만 넣으므로 광고 옵션ID 개수는 쿠폰 SKU 개수보다 적을 수 있습니다.
3. **쿠폰·광고 파일 함께 받기** 또는 위쪽 **쿠폰·광고 파일 받기 ↓**를 누릅니다. **전체 파일 한 번에 받기 ↓**에도 같은 광고 파일이 포함됩니다.
4. 받은 ZIP에서 쿠폰 엑셀과 **3-1_광고등록.xlsx**부터 시작하는 광고 엑셀을 확인합니다. 최종 상품 선택을 바꾸었다면 이전 파일 대신 새로 생성한 파일을 사용하세요.

### 광고 옵션ID는 한 파일에 최대 500개

| 중복을 제거한 옵션ID 수 | 생성되는 광고 파일 |
| --- | --- |
| 1~500개 | **3-1_광고등록.xlsx** 1개 |
| 501~1,000개 | **3-1_광고등록.xlsx** 500개 + **3-2_광고등록.xlsx** 나머지 |
| 1,001개 | **3-1_광고등록.xlsx** 500개 + **3-2_광고등록.xlsx** 500개 + **3-3_광고등록.xlsx** 1개 |

광고 양식은 **Sheet1의 A1 ‘옵션ID’**를 유지하고 **A2부터 옵션ID만 한 줄씩** 입력합니다. 다른 상품정보를 붙이거나 여러 파일을 500개 넘게 합칠 필요가 없습니다.

### 옵션ID가 없거나 서로 다를 때

**옵션ID 확인 필요 N개 SKU**를 펼치면 **옵션ID 없음 / 옵션ID 불일치**인 SKU와 상품명이 표시됩니다. 한 상품이라도 연결을 확인하지 못하면 **쿠폰·광고 함께 받기와 전체 파일 생성이 차단**됩니다. 확인되지 않은 상품을 조용히 빼고 광고 파일을 만들지 않습니다.

해당 SKU의 옵션ID 연결을 확인한 뒤 **광고 옵션ID 다시 확인**을 누르세요. 광고 연결 확인을 기다리는 동안에도 **쿠폰만 받기**로 현재 선택한 쿠폰 엑셀을 먼저 받을 수 있습니다.

### 쿠팡 광고관리센터에 등록

[쿠팡 광고 등록 화면 열기](https://advertising.coupang.com/marketing/campaign/registration?goalType=SALES)에서 상품 대량등록 기능을 사용합니다. 생성된 **3-1, 3-2, 3-3 파일을 각각 순서대로** 등록하고 화면의 등록 결과를 확인하세요. 파일 한 번에 최대 500개입니다.

**파일 생성은 광고 등록 완료가 아닙니다.** 쿠팡에서 직접 등록을 마쳐야 합니다. 주간 업무의 **쿠팡에 등록했어요**는 쿠폰 등록 완료 표시이며, 광고 등록까지 자동으로 처리하거나 확인하지 않습니다.

## 05. 미입고 상품 검토

처음에는 **확인 필요** 상품이 보입니다. **전체 / 재발주요청 / 보류 / 단종** 필터와 SKU·상품명·거래처 검색으로 대상을 찾으세요.

### 거래처 발주에 필요한 사진과 거래처

1. **사진 추가**로 파일을 고르거나 사진 영역에 **Ctrl+V**로 이미지를 붙여넣습니다.
2. 잘못되거나 깨진 사진은 **사진 변경**으로 바꾸세요. 사진은 다음 작업에도 재사용합니다.
3. **거래처**를 선택하거나 입력합니다. 같은 거래처는 같은 이름으로 입력하세요.

### 수량은 이렇게 읽으세요

| 화면의 수량 | 뜻 |
| --- | --- |
| 발주 확정 | 원문 H열과 발주이력의 대조가 끝난 해당 SKU 확정수량 합계 |
| 실제 누적 입고 | 원문 I열로 검산한 해당 발주서의 누적 입고에서 반출을 뺀 수량 |
| 쿠팡 미입고 | 원문 대조가 끝난 확정수량에서 실제 누적 입고를 뺀 양수 부족수량 |
| 기존 거래처 주문 잔량 | 이미 거래처에 주문했고 아직 남아 있는 것으로 연결된 수량 |
| 추가 주문 제안 | 기존 주문 등을 대조해 제안하는 수량. 기존 12개 단위 주문 규칙이 적용됩니다. |
| 거래처에 주문할 수량 | 이번 발주 파일에 들어갈 최종 수량. 필요하면 직접 수정합니다. |

미입고 18개, 기존 주문 잔량 6개라면 추가 필요량은 12개입니다. **현재 사용 가능한 재고와 배송 상태도 확인**한 뒤 주문수량을 정하세요.

**거래처에 주문할 수량**은 직접 수정할 수 있지만, 검증된 **쿠팡 미입고** 수량은 바뀌지 않습니다.

원문이 없거나 맞지 않는 **자료 확인 필요** 상품은 목록 밖에 표시됩니다. 주문수량을 임의 입력하지 말고 03장에 따라 자료를 보완하세요.

### 수량 확인을 한 번에 마치기

미확인 상품은 **기존 주문과 배송 진행 상태를 확인했으며, 이 수량으로 주문합니다.**를 체크합니다. 확인을 마친 현재 목록은 **표시된 N개 주문수량 확인**으로 함께 처리할 수 있습니다. 사진·거래처·양수 수량이 준비된 상품만 적용됩니다.

처음 40개 이후는 **다음 40개 더 보기**를 누르세요. 일괄 확인은 현재 검색·필터에 표시된 대상만 적용됩니다.

### 보류·단종과 저장

**처리 방법 → 이번에는 보류**는 이번 발주에서 제외하고 다음 업무에 이어서 검토할 때 사용합니다. **단종 · 생산 종료**는 생산 종료를 확인한 상품에 사용합니다. 변경 후 **검토 내용 저장됨**을 확인하고 화면을 나가세요.

## 06. 재고가 있으면 쿠팡 재발주요청

거래처에 새로 구입할 필요 없이 **보유 재고로 출고할 수 있는 미납 상품**에 사용합니다. 실제 입고가 시작되고 원문 대조까지 통과한 발주서의 부족분만 대상입니다. 입고가 전혀 없거나 자료가 불확실한 발주 건은 포함하지 않습니다.

### 선택부터 요청 완료까지

1. **미입고 상품을 검토하세요**에서 SKU를 찾고, **처리 방법 → 재발주요청 · 재고 있음**을 선택합니다. **사진 추가·거래처 선택은 필요하지 않습니다.**
2. 상품 아래 **원래 발주번호 / 미납수량 / 처리** 표를 확인합니다. 같은 SKU가 두 발주서에서 부족하면 발주번호별로 각각 나옵니다. **재발주요청** 필터로 모아 볼 수 있습니다.
3. **검토 내용 저장됨**을 확인하고 **미납발주건 재발주요청 엑셀**을 누릅니다. **전체 파일 한 번에 받기 ↓**에도 포함됩니다.
4. 생성 결과의 **요청입고예정일**과 엑셀 내용을 확인합니다. [쿠팡 미납발주건 요청 화면 열기 ↗](https://supplier.coupang.com/plan/ticket/reportIssue/Reorder)를 눌러 **대량 가져 오기**에서 생성한 엑셀을 선택하고 요청을 진행합니다.
5. 실제 요청을 마친 뒤 **쿠팡에 재발주 요청했어요**를 누릅니다. 요청 내역과 완료 시각은 거래처 발송 기록과 별도로 저장됩니다.

### 요청수량·예정일·사유

| 항목 | 자동 입력 기준 |
| --- | --- |
| 발주 요청수량 | 원래 발주번호·SKU별 확정수량에서 누적 순입고를 뺀 정확한 부족수량. 12개 단위로 올리지 않습니다. |
| 요청 입고예정일 | 파일을 만든 날 다음의 첫 금요일. 금요일에 만들면 다음 주 금요일입니다. |
| 요청사유 | **업체실수로 인한 출고누락** |

예를 들어 같은 SKU가 A 발주서에서 3개, B 발주서에서 5개 부족하면 **3개와 5개를 두 행으로 요청**합니다. 2026년 9월 7일에 만들면 예정일은 **9월 11일**, 9월 11일에 만들면 **9월 18일**입니다.

### 이전 분석·이미 요청한 항목

**발주번호별 미납수량을 다시 확인해야 합니다**가 보이면 원문과 이력을 보완하고 **최신 자료로 다시 확인**을 누르세요. 미완료 재발주 검토는 같은 기간의 새 미납 SKU에 이어집니다. **자료 확인 필요**에 남은 상품은 재발주 파일에 포함되지 않습니다.

다른 작업에서 이미 요청한 같은 발주번호·SKU는 **기요청 · 제외**로 표시되어 새 요청 파일에서 빠집니다. 아직 요청하지 않은 발주번호만 파일에 포함됩니다.

엑셀은 쿠팡 `issueReport` 양식을 유지합니다. **1행 고유정보와 2행 제목은 그대로 두고**, 3행부터 SKU·발주번호·수량·예정일·사유가 채워진 내용을 확인하세요. 파일 생성만으로 쿠팡에 자동 제출되지는 않습니다.

## 07. 파일 받기와 실제 처리 완료

### 필요한 파일을 받으세요

**전체 파일 한 번에 받기 ↓**는 쿠폰·광고등록·거래처 발주·재발주요청·단종 파일을 하나의 ZIP으로 만듭니다. 상품 검토와 광고 옵션ID 확인을 마쳐야 사용할 수 있습니다. 생성된 파일 목록에서 개별 파일도 받을 수 있습니다.

| 화면 버튼 | 생성 결과 |
| --- | --- |
| 쿠폰·광고 파일 함께 받기 | 선택 SKU의 쿠폰 엑셀 + 옵션ID 최대 500개씩 담은 광고 엑셀. 거래처 검토와 별도로 받습니다. |
| 거래처 발주 이미지·엑셀 | 사진이 들어간 PNG와 사진 링크가 있는 엑셀. PNG는 상품 8개씩 나뉘므로 한 거래처에 여러 장이 생길 수 있습니다. |
| 미납발주건 재발주요청 엑셀 | 원래 발주번호·SKU별 미납수량, 다음 첫 금요일 예정일과 요청사유를 담은 쿠팡 양식 |
| 단종 공문 PDF·SKU 엑셀 | 단종을 선택한 상품의 공문 PDF와 동일 대상 SKU 엑셀 |

**쿠폰만 받기**는 광고 옵션ID가 준비되지 않아도 쿠폰 엑셀을 받는 버튼입니다. 쿠폰은 체크한 SKU만 담고, 이미 등록 완료한 동일 입고는 새 쿠폰에서 제외됩니다. 과거 파일은 중복 등록하지 않도록 확인하세요.

### 파일을 사용한 다음 완료 표시

| 실제로 한 일 | 그다음 누를 버튼 |
| --- | --- |
| 쿠팡에서 쿠폰 엑셀 등록을 마침 | **쿠팡에 등록했어요** |
| 해당 거래처에 사진 발주서·엑셀을 보냄 | 거래처 이름 옆 **거래처에 보냈어요** |
| 쿠팡에 미납발주건 재발주 요청을 마침 | **쿠팡에 재발주 요청했어요** |
| 쿠팡에서 단종 공문과 SKU 파일로 신청을 마침 | **쿠팡에 신청했어요** |
| 이번에 처리할 항목의 등록·발송·신청을 모두 마침 | **이번 주간 업무 완료** |

실제 발송·요청·신청 후 완료를 기록하세요. 사이트가 카카오톡을 보내거나 쿠팡에 자동 제출하지는 않습니다. 선택한 쿠폰이 0개면 쿠폰 완료 항목은 없습니다. 거래처 발송 완료는 기존 발주·입고관리와 연결됩니다.

### 거래처가 나중에 “단종”이라고 답하면

**지난 작업 이어보기**에서 해당 작업을 열고 **전체**에서 SKU를 찾습니다. **처리 방법 → 단종 · 생산 종료**로 바꾼 뒤 **단종 공문 PDF·SKU 엑셀**을 새로 받으세요. 신청을 마치면 **쿠팡에 신청했어요**를 누릅니다.

이미 보낸 발주 수정은 **거래처 발주관리 ↗**에서 진행합니다. 단종 SKU를 추가했다면 새 파일의 대상을 다시 확인하세요.
