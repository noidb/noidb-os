- 화면 검토 이후 사용자 승인에 따라 1단계를 로컬 체크포인트 커밋으로 저장한다. push·운영 배포는 하지 않는다.
- 선별 범위는 물류 화면/저장소/API, 날짜별 검증 출력, 관련 작업센터 UI와 검사 스크립트다. 기존 직접 바코드 API의 7열 양식 변경도 보존하지만, 최종 날짜 출력은 실제 동봉내역서·쉽먼트 수량을 대조하는 별도 경로를 사용한다.
- 입고/미납 화면과 API, 정적 flow-preview, 테스트 운영자료 생성/삭제 스크립트, 백업 폴더는 커밋에서 제외하고 원본을 보존한다. 공통 파일 안의 입고마감 배너 및 확정수량을 원발주 수량으로 대체하는 미사용 옵션은 별도 미커밋 변경으로 남긴다.
- 실제 운영 기록 변경, 쿠팡/한진 업로드, 카카오톡 전송, 인쇄는 하지 않았다.
- 검토 화면: `http://localhost:3111/wms/logistics/new-orders?logisticsFixture=1`. 예시자료임을 노란 안내로 표시한다.
- 실제 신규 발주 가져오기부터 Drive 저장·한진 발번·쿠팡 등록·실물 인쇄까지의 업무 검증은 사용자 화면 확인 이후 별도로 진행해야 한다.
