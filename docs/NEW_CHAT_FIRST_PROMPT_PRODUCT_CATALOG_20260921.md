4. 사진 폴더 미선택이나 권한 오류가 있으면 추측으로 우회하지 말고 원인을 정확히 보고한다.
5. Excel 통합 파일과 운영 Google Sheets를 바로 병합하지 말고, staging·중복 검토·불일치 검토 방식만 설계한다.
