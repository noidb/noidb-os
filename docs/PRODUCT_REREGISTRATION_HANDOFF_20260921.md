# 상품 재등록·사진 연결 인수인계 — 2026-09-21

## 회사에서 시작하기

1. PC Chrome 또는 Edge에서 [상품 연결 대장](https://noidb-os.vercel.app/wms/product-catalog)을 연다. 집 PC의 localhost:3010 주소를 회사에서 사용하지 않는다.
2. 회사 PC의 MYBOX 동기화 사진 폴더가 탐색기에 보이는지 확인한다. 집에서 쓰던 드라이브 문자가 회사와 같을 필요는 없다.
3. 화면의 **사진 원본 폴더 연결**을 눌러 사진 최상위 폴더를 선택한다. 이 권한·폴더 연결은 회사 PC에서 다시 설정해야 한다.
4. **재등록 필요(모델 전체)** → 모델 검색 → **이 모델 사진 검색** → 사진 체크(최대 10장) → **등록 준비** 순서로 진행한다.
5. 먼저 한 모델로 사진 미리보기와 등록 화면 전달을 확인한다. 실제 등록 저장·쿠팡 제출까지 검증된 상태는 아니다.

폴더 핸들, 선택 사진, 등록 준비 데이터와 WIMS 브라우저 스냅샷은 같은 PC·브라우저·사이트 안에 저장된다. 집에서 선택한 사진이나 연결한 폴더가 회사로 자동 이전되지 않는다. MYBOX 웹 로그인만으로 폴더 연결이 되는 것도 아니다. 회사 PC에서 읽을 수 있는 동기화 폴더가 필요하다.

## 업무 목표와 확정 기준

- 최우선은 판매중지 상품 재등록. 한 모델의 옵션 하나가 판매중지되고 전 옵션 링크가 죽은 경우, 모델 전체 옵션을 재등록 대상으로 준비한다. 이후 아직 로켓에 등록하지 않은 상품을 처리한다.
- 모델명은 사진 폴더·상품군 키다. 모델SKU는 옵션 식별자다. SKU ID는 쿠팡 승인 후 발급된다. 모델명만으로 옵션을 합치거나 기존 SKU를 대체하지 않는다.
- `G:\내 드라이브\쿠팡데이터\상품공급상태관리 다운로드`의 최신 공급상태 파일이 SKU ID별 바코드·상품명·발주가능상태의 기준이다. 다른 열과 이력까지 일괄 덮어쓰는 뜻은 아니다.
- 재등록 전후 SKU·바코드 이력, 누적입고·재고·창고정보를 보존한다. 링크 누락 또는 조회 실패만으로 판매중지나 미등록을 확정하지 않는다.
- 반려건은 반려 상태·등록일·확인된 반려일·사유를 별도로 남겨 보완 재등록에 사용한다. 등록일을 반려일로 대신 표시하지 않는다.
- 최근 승인 9 SKU와 반려 2건이 사용자 확인 대상이었다. 이전 시점 파일에는 승인 9건이 없을 수 있다. 최신 원본으로 구분한다.
