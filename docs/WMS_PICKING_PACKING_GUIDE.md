# 상품 찾기 → 센터 분배 → Shipment 검수·포장 → 출고완료

## 1. 출력물을 준비합니다
서류 화면에서 Shipment 출력세트를 생성하고, 필요한 동봉내역서·라벨·바코드를 출력합니다. 바로 아래 **실제 피킹 시작하기 →**를 누릅니다.

## 2. 상품을 찾고 센터별로 나눕니다
- 통합 피킹 목록은 **창고번호 → 모델 → 옵션 → SKU** 순서입니다.
- 오른쪽 `3 / 3개`는 **찾은 수량 / 발주 총수량**입니다. 센터 개수나 Shipment 개수가 아닙니다.
- 상품 아래에 센터·입고예정일·분배 수량을 줄마다 표시합니다. 같은 SKU가 여러 센터에 필요하면 모든 센터가 표시됩니다.
- 예: `대구3 1개`, `동탄1 2개`이면 총 3개를 찾아 각각 나눕니다. 피킹 수량을 확정한 상품은 저장된 분배 수량을 표시합니다.
- 2026-09-06 확인한 테스트 작업의 SKU 38256611은 대구3 발주 140872812의 3개입니다. 저장된 이번 작업 915 SKU에는 여러 센터에 걸친 동일 SKU가 없었습니다.

## 3. Shipment별 검수·포장으로 이동합니다
상품 찾기 목록의 위 또는 아래에서 **찾기·센터 분배 후 → Shipment별 검수·포장**을 누릅니다.

화면은 출력세트에 사용한 Shipment XLSX와 실제 동봉내역서 PDF를 다시 대조합니다. SKU·바코드·수량·발주번호가 일치한 목록만 보여줍니다. 아직 Shipment 파일이 없는 발주가 있으면 서류 화면에서 먼저 생성합니다.

## 4. 포장할 Shipment를 선택합니다
**포장할 Shipment**에서 물류센터와 Shipment 번호를 확인합니다. 같은 센터라도 Shipment 번호가 다르면 따로 포장합니다.

상품은 해당 동봉내역서의 순서대로 나옵니다. 번호·상품명·옵션·SKU·바코드와 **이 Shipment에 N개**를 확인합니다. 검색해도 원래 순서와 번호는 유지됩니다.

## 5. 상품 확인 → 바코드 부착 → 박스에 넣기
1. 이미지를 눌러 크게 보거나 **상품 링크 열기 / 상품정보 보기**로 상품을 확인합니다. 상품정보는 새 탭에서 열립니다.
2. 이 Shipment에 필요한 수량을 확인합니다.
3. 바코드를 붙이고 해당 Shipment 박스에 넣습니다.
4. **N개 확인 · 바코드 부착 · 박스 포장**에 체크합니다.

체크는 기존 피킹 수량과 별도로 공용 저장됩니다. 새로고침해도 체크가 유지됩니다. 저장 실패 메시지가 나오면 저장된 것으로 간주하지 말고 새로고침 후 확인합니다. 다른 기기에서 같은 기록을 바꾸었으면 최신 기록을 다시 불러옵니다.

## 6. 바코드가 분실되거나 손상됐을 때
1. 해당 상품의 **바코드 분실·손상 → 재발행**을 펼칩니다.
2. 필요한 장수를 입력합니다. 기본은 1장이고, 해당 Shipment 상품 수량까지만 입력할 수 있습니다.
3. **이 상품 바코드 재발행**을 누릅니다.
4. 다운로드된 XLSX를 기존 BarTender 양식으로 열어 출력합니다.

제품DB에 제조국·영문 모델 정보가 없는 상품은 목록은 볼 수 있지만 재발행은 차단됩니다. 해당 상품정보를 확인하고 목록을 새로고침합니다.

다른 상품은 함께 재발행하지 않습니다. 기존 양식의 Shipment 구분행은 유지됩니다. 실제 프린터 출력은 사용자가 진행합니다. 재발행으로 피킹 수량이나 포장 체크가 변하지 않습니다.

## 7. 실제 택배사 인계 후 출고완료
모든 Shipment의 상품을 체크하면 **택배 인계 후 · 출고완료** 버튼이 활성화됩니다. 실제로 택배사에 인계한 뒤 누르고 확인창에서 확인합니다.

Shipment·출력세트·피킹 기록이 남아 있으면 완료할 수 없습니다. 정상 완료되면 완료 시각이 저장되고 작업센터에서도 완료 작업으로 표시됩니다. 재고나 기존 피킹 수량을 임의로 변경하지 않습니다.

## 출력 내용이 바뀌었다면
송장 분할·Shipment 파일·출력 대상이 바뀌면 이전 체크를 새 목록에 자동 적용하지 않습니다. **변경된 목록으로 검수 시작**을 눌러 새 동봉내역서 기준으로 확인합니다. 이미 출고완료한 기록은 다시 덮어쓰지 않습니다.
