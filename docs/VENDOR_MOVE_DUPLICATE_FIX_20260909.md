확인한 결함:
- 이동 사전검사는 저장된 서버 행만 검사하고 화면의 미저장 행을 검사하지 않았다.
- 서버 SKU 검사에는 신규 행만 포함되어 기존 행 ID를 유지하는 거래처 이동이 검사에서 빠졌다.
- 이동 완료 후 화면 배열과 최신 참조를 함께 갱신하지 않았다.

수정:
- 저장된 행과 미저장 행 모두 대상 거래처의 정규화 SKU로 검사한다.
- 기존 행을 다른 발주서로 옮기는 저장도 대상 발주서 중복 SKU를 검사한다.
- 정상 이동은 원래 행 ID, 수량, 메모와 입고 기록을 유지하며 화면의 최신 참조와 초안 기준값도 갱신한다.
- 이전 보관 발주서는 현재 이동 대상에서 제외한다.
- 상품 검색으로 추가할 때도 최신 참조를 즉시 갱신한다.
