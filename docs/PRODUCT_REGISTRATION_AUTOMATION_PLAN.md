# NOID-B 상품등록 자동화 정비안

## 목표

상품 기획부터 쿠팡 승인 SKU 반영까지를 하나의 상태 흐름으로 관리하고, 사용자는 예외 확인과 Supplier Hub 최종 업로드만 담당한다.

## 확인된 현재 구조

1. AI 상품등록 도우미의 일괄 생성은 상품 이미지·상세 이미지·라벨·견적서를 만들고 Google 상품DB에 승인대기 행을 누적한다.
2. 라벨·견적서·상세 이미지·상품 이미지는 독립 다운로드가 가능하다. 독립 실행은 Google 상품DB를 수정하지 않는다.
3. 승인 SKU 반영 경로가 두 개다.
   - 메인 화면에서 상품공급상태 XLSX를 직접 올려 Apps Script로 반영
   - 작업센터에서 Drive/로컬 최신 XLSX를 찾아 미리보기 후 Sheets API로 반영
4. 신규 승인 연결은 `모델SKU | 실제옵션명`을 최우선 키로 사용한다. 기존 SKU 행은 SKU로 연결하고 상품명·바코드·발주가능상태만 갱신한다.
5. 상품공급상태 동기화는 제품DB 신규행을 만들지 않는다. S 바코드는 제외하며, 중복·충돌이 하나라도 있으면 쓰기를 차단한다.

## 목표 흐름

`등록준비 → 파일생성 → Supplier Hub 업로드 대기 → 승인 대기 → 승인 SKU 자동연결 → 운영중 → 판매중지/재등록 검토`

각 모델과 옵션 행에 상태, 마지막 확인일, 원본 파일, 매칭 규칙, 예외 사유를 남긴다. 파일명이나 상품명 유사도는 보조 증거로만 사용하고 모델SKU와 SKU를 기본 키로 삼는다.

## 구현 순서

### 1단계: 등록 작업 단순화

- 일괄 생성과 개별 파일 생성을 명확히 분리한다.
- 라벨은 모델명·제조연월·제조자명·수입자명을 현재값으로 미리 채우고 `상품이미지DB/라벨`에 단독 저장한다.
- 일괄 생성 전 결과 파일과 Google 상품DB 변경 행을 한 화면에서 미리 보여준다.
- 생성 성공, 로컬 저장 성공, Google Sheet 반영 성공을 서로 다른 상태로 표시한다.

### 2단계: 승인 SKU 동기화 단일화

- 작업센터의 `상품공급상태 업데이트`를 유일한 운영 진입점으로 정한다.
- 최신 XLSX 자동 탐색, S 바코드 제외, 신규행 0건, 변경 셀 미리보기, 전체 시트 백업, 원자적 반영을 유지한다.
- 메인 화면 직접 업로드는 같은 미리보기 API를 호출하는 수동 대체 경로로 바꾸고 별도 Apps Script 매칭 구현은 제거한다.
- 결과를 `자동연결 / 승인대기 / 중복 / 충돌 / 기존 SKU 갱신` 다섯 묶음으로 보여주고 사람이 볼 것은 중복·충돌만 남긴다.

### 3단계: 매칭과 예외 자동화

- 신규 SKU: 명시 모델SKU 완전일치 → 옵션 완전일치 → 정규화 상품명 점수 순으로 후보를 만든다.
- SKU가 이미 있는 행: SKU 완전일치만 허용하고 상품명·발주가능상태를 갱신한다. 바코드는 불변값으로 취급하며 다운로드 값이 다르면 자동 수정하지 않고 충돌로 보고한다.
- 동일 다운로드 SKU가 여러 제품DB 행에 연결되거나 후보가 복수이면 전체 자동 반영에서 제외한다.
- 승인대기 행에 `마지막 확인일`과 `다음 확인 권장일`을 남겨 같은 파일을 반복 확인하는 일을 줄인다.

### 4단계: 사용하지 않는 기능 정리

- `기존 SKU 연결`은 최근 사용 여부와 성공 사례를 먼저 기록한다.
- 사용하지 않는 것이 확인되면 화면에서 숨기고, 한 배포 주기 동안 데이터·API는 유지한다.
- 문제가 없을 때만 Apps Script의 구형 연결 함수와 중복 UI를 삭제한다. 제품DB 기존행이나 SKU 교체이력은 삭제하지 않는다.

## 사람에게 남길 일

- Supplier Hub에 등록파일과 견적서를 최종 업로드하는 일
- 중복 후보 또는 바코드 충돌 검토
- 판매중지 SKU의 삭제/재등록 결정
- 배포 및 실제 외부 제출 최종 승인

## 완료 기준

- 제품DB 신규행 생성 0건
- S 바코드 반영 0건
- 같은 SKU의 복수 행 배정 0건
- 자동 반영 결과에 원본 파일명·행번호·매칭 규칙·변경 전후값 기록
- 라벨 단독 작업이 다른 파일 생성이나 Google Sheet 쓰기를 유발하지 않음
- 실패 시 일부 반영 없이 전체 차단하고 재실행 가능한 미리보기 제공
