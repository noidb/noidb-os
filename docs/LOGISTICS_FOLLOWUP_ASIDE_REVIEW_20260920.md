## 서류 작업과 거래처 관리 분리 — 추가 승인 반영

- 누적을 기다릴지는 사용자가 결정한다. 파일 생성 당시 포함한 출처만 완료하며 이후 추가된 상품·요청은 남긴다. 현재 대기 출처 수와 생성 파일의 실제 대상 수를 구분한다. 같은 대상 파일을 다시 생성하고 완료해도 이전 미완료 파일이 다시 활성화되지 않는다.
