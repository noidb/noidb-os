데이터 없음

    
    

      상세 진단 보기
      

      

      
    

    

      실제 확인된 DOM(기간검색 select, 어제/오늘/다음7일/다음30일 프리셋,
      검색 버튼) 기준으로 "기간검색=발주일 / 오늘 기준 과거 30일"을 최초
      1회만 자동 적용합니다. "다음 30일"은 절대 클릭하지 않으며, 날짜 입력칸을
      클릭해 실제 달력을 연 뒤 시작일/종료일 날짜 셀을 직접 클릭해서 범위를
      맞춥니다(입력값 강제대입 아님). 각 단계가 실제로 반영됐는지 스스로
      검증하며, 확인되지 않으면 검색을 누르지 않고 플래그도 세우지 않습니다
      (다음 진입 때 자동 재시도). 한 번 성공한 뒤에는 사용자가 과거 조회를
      위해 직접 기간을 바꿔도 다시 건드리지 않습니다.
