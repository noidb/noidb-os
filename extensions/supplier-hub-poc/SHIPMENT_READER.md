# 쉽먼트 입고결과 일괄 수집 (0.9.9)

## 0.9.9 (2026-10-11)

- 사이트가 이미 받은 마감 쉽먼트는 상세를 다시 열지 않고, 새로 마감된 쉽먼트만 읽는다. 공급상태도 새 쉽먼트의 SKU만 조회한다.
- 쿠팡 메뉴로 쉽먼트 목록에 들어와도(새로고침 없이) 칸이 뜬다.
- 설치 파일: https://noidb-os.vercel.app/downloads/noidb-supplier-hub.zip (이름 고정) — 처음 한 번만 압축을 풀어 `noidb-supplier-hub` 폴더를 "압축해제된 확장 프로그램을 로드합니다"로 불러온다(예전 0.9.8은 끈다). 다음부터는 같은 폴더에 덮어쓰고 chrome://extensions에서 새로고침만 한다. 확장을 고치면 이 zip도 같은 이름으로 다시 만든다.

발주번호를 하나씩 입력하지 않습니다. 사이트에 저장된 출고 건과 Aside에서 이어받은 대기 쉽먼트를 한 번에 확인합니다.

## 이번에 한 번만: 설치 위치 변경

현재 크롬에는 다른 폴더의 구버전 0.9.2가 설치돼 있습니다. 그 확장의 새로고침만으로는 업데이트되지 않습니다.

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 기존 **NOID-B Supplier Hub POC (Read-Only)**의 스위치를 꺼 둡니다.
3. 오른쪽 위 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 폴더 `E:\노이드비AI\extensions\supplier-hub-poc`를 선택합니다. 새 확장의 버전이 **0.9.5**인지 확인합니다.

## 매번 사용하는 순서

1. 로그인한 크롬에서 [쿠팡 쉽먼트](https://supplier.coupang.com/ibs/asn/active)를 열고 새로고침합니다.
2. 화면 위 **입고결과 일괄 가져오기**를 누릅니다.
3. **NOID-B 저장 완료**가 표시되면 [사이트 입고결과](https://noidb-os.vercel.app/wms/inbound/shipments)에서 **새로고침**합니다.

쿠팡 자료는 조회만 합니다. 미마감은 대기하며, 마감된 쉽먼트의 실제 수량과 SKU 공급상태가 모두 확인된 경우에만 저장합니다. 일부 조회가 실패하면 부분 자료를 완료로 저장하지 않습니다. 전송 실패 때는 **NOID-B 전송 재시도** 또는 **자료 파일 저장**을 사용할 수 있습니다.

미납 SKU는 단종·거래처발주·미납분 재발주요청으로 분류하고, 1개 입고 후보는 제외 선택 후 쿠폰·광고로 보냅니다. 파일 생성 뒤 쿠팡에서 실제 처리를 마친 다음 사이트에서 **처리완료**를 누릅니다.

검증: `node scripts/verify-logistics-receipt-extension.cjs`. 새 설치본으로 로그인된 쿠팡에서 전체 수집·운영 전송을 실행하는 실제 업무 확인은 아직 수행하지 않았습니다.
