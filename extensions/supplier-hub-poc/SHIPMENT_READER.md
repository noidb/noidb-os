# 쉽먼트 입고결과 수집 (0.9.3)

기존 확장프로그램을 새로고침하면 쿠팡의 **택배 쉽먼트** 화면 위에 수집 버튼이 표시됩니다.

1. NOID-B의 **입고결과 처리 → 쉽먼트 입고결과 가져오기**에서 확인할 발주번호를 입력합니다.
2. **쿠팡에서 가져오기**를 누르면 같은 발주번호가 쿠팡 수집 칸에 채워집니다.
3. **쉽먼트 입고결과 가져오기**를 누릅니다.
4. 조회가 끝나면 **NOID-B로 전송**을 누릅니다. NOID-B에서 **새로고침**하면 저장 결과가 보입니다.

운영 API가 아직 준비되지 않았으면 전송하지 않고 안내합니다. **자료 파일 저장**으로 JSON을 보관했다가 NOID-B 화면에서 가져올 수도 있습니다.

- 쿠팡에는 조회 요청만 보냅니다. 발주확정, 쉽먼트 수정, 업로드, 삭제는 하지 않습니다.
- 입력한 발주번호의 전체 조회 페이지를 확인합니다. 일부 조회가 실패하면 부분 자료를 완료로 저장하지 않습니다.
- 마감된 쉽먼트의 상세 행을 읽고, SKU 합계와 쉽먼트 총수량을 대조합니다.
- 연결된 쉽먼트 중 하나라도 마감 전이면 최종 입고수량 확정을 보류합니다.
- 같은 자료를 재전송해도 입고수량이 늘어나지 않습니다. 더 오래된 자료는 최신 자료를 덮어쓰지 못합니다.
- 9월 17일 당시의 마감 상태를 현재 날짜 정보로 추정하지 않습니다.
- 현재 수집 기능은 별도 원자료 저장 단계입니다. 미납 분류·광고·쿠폰·최종 완료로의 연결은 아직 완료되지 않았습니다.

개발 검증: `node scripts/verify-shipment-receipts.cjs`.
실제 Chrome 확장프로그램 새로고침 이후의 버튼 실행과 운영 API 전송은 별도로 확인해야 합니다.
